# SwiftViana — Informasi Proyek

**Nama bot:** SwiftViana  
**Brand:** ©Viana Studio  
**Maintainer:** @rasyaardi

SwiftViana merupakan bot WhatsApp berbasis Node.js dan Baileys. Proyek ini menggabungkan source code, dependensi, dan aset yang dapat memiliki asal serta lisensi berbeda. Label maintainer di atas mengidentifikasi pemeliharaan dan brand proyek ini; label tersebut tidak menyatakan bahwa semua dependensi atau aset pihak ketiga dibuat oleh maintainer.

## Penggunaan

- Konfigurasi bot berada di `config/settings.js`.
- Isi nomor WhatsApp owner milik sendiri pada `settings.ownerNumbers` sebelum mengandalkan perintah owner dari akun lain.
- Isi `PAIRING_NUMBER` di panel untuk membuat pairing code.
- DANA dan QRIS sengaja dibiarkan belum dikonfigurasi supaya detail pembayaran operator sebelumnya tidak ikut terbawa.

## Sumber dan lisensi

Referensi aset RPG, fishing, dan reply-style tetap dicantumkan pada file `SOURCES.md` dan `LICENSE.txt` di folder aset masing-masing. Dependensi npm dan fork yang diperlukan untuk menjalankan fitur tetap menggunakan referensi paket aslinya; jangan menghapus atau mengganti lisensi dependensi tanpa audit kompatibilitas.
